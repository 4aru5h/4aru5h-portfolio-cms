# 4aru5h-portfolio-cms

Personal portfolio website with an integrated content management system.

[Live Site](https://4aru5h.in)

---

## Overview

Allows managing portfolio content (projects, experience, certifications) through an admin dashboard without manual code changes.

- **Client:** React frontend with responsive styling and administrative routes.
- **Server:** Node.js and Express REST API with session authentication.
- **Database:** PostgreSQL for structured content persistence.

---

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables in `.env` based on `.env.example`.
3. Run locally:
   ```bash
   npm run dev
   ```
